# CoreCaseX Website

Static GitHub Pages website for CoreCaseX, a Paper staff-case system with guided player reports, staff workflows, SQLite history, and optional Discord webhooks.

The site uses plain HTML, CSS, JavaScript, and SVG. FrameBaseCSS `1.2.0` supplies the theme and component foundation; Highlight.js `11.11.1` and the FrameBaseCSS addon highlight configuration examples. Released assets are pinned under `assets/vendor/`.

## Pages

- `index.html`: product overview.
- `features.html`: player, staff, evidence, notification, and storage workflows.
- `installation.html`: Paper installation and first startup.
- `configuration.html`: complete configuration reference.
- `docs.html`: documentation hub.
- `faq.html`: practical questions and troubleshooting.
- `support-policy.html`: release and support policy.
