# CoreCaseX Website

Static GitHub Pages website for CoreCaseX.

## Structure

- `index.html` - landing page
- `features.html` - product overview
- `installation.html` - setup guide
- `configuration.html` - configuration reference
- `docs.html` - documentation hub
- `faq.html` - FAQ
- `assets/` - logo, CSS, and shared JavaScript

The website uses a static multi-page publishing model while keeping all content specific to CoreCaseX.
