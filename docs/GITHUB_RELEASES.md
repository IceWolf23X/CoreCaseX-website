# CoreCaseX public release view

The browser release tab reads unauthenticated public metadata from `IceWolf23X/CoreCaseX-website`. An empty release catalog is a valid current result and must be rendered honestly.

The main Download action points to <https://modrinth.com/plugin/corecasex>, where the current 2026.1.1 file is marked beta. The website release source does not replace Modrinth and does not infer stable status from a filename or internal descriptor.

No browser credential is used. A generated offline release snapshot is optional and must represent only public website-repository releases. Creating or publishing a release remains a separate authorized operation.
