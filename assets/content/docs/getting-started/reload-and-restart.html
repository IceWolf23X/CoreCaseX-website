Use /case reload for YAML changes

Reload reads config.yml, case-types.yml, messages.yml, storage.yml and discord.yml, then logs validation warnings. Missing bundled YAML files are recreated during this load, so reload can regenerate a deleted default.

Restart for runtime identity

  • Replacing the plugin JAR.
  • Changing Paper or Minecraft version.
  • Changing storage.yml -> sqlite.path. Reload reads the new text but does not close and reopen the initialized SQLite backend.
  • Taking the safest complete backup of the SQLite file.

Regenerate one default safely

  1. Stop the server and back up plugins/CoreCaseX/.
  2. Delete only the YAML file that must be regenerated.
  3. Start the server, or use /case reload if the server is already running and the missing file is not the database.
  4. Reapply intended settings from the backup.

Never delete data/corecasex.db unless removing every case and its history is intentional.
