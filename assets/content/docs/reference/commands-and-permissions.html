Permission reference

Player permissions, default true

corecasex.use, corecasex.case.create, corecasex.case.list, corecasex.case.view-own.

Staff permissions, default op

corecasex.staff.board, corecasex.staff.view, corecasex.staff.claim, corecasex.staff.assign, corecasex.staff.note, corecasex.staff.reply, corecasex.staff.request-info, corecasex.staff.priority, corecasex.staff.status, corecasex.staff.resolve, corecasex.staff.reject, corecasex.staff.archive, corecasex.staff.teleport, corecasex.staff.view-evidence, corecasex.staff.view-sensitive-evidence.

Administrator permissions, default op

corecasex.admin.reload, corecasex.admin.debug.

Recommended responsibility split

Give normal players only the four player permissions. Helpers may receive board/view/reply/request-info. Add claim, notes, priority, status, resolve and reject according to moderation responsibility. Restrict archive, teleport and sensitive evidence to trusted roles.
