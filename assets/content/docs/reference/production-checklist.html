Production validation checklist

  • Boot Java 21 and Paper 1.21.11+ without runtime-guard or storage errors.
  • Run /case and verify the inventory-first main menu.
  • Create all five case types and inspect the resulting location/evidence behavior.
  • Verify open-case limit and cooldown with a non-op player.
  • Inspect the reporter's list/details and reject access to another reporter's ID.
  • Exercise every staff board filter.
  • Claim, assign and reassign to an online player; confirm timeline values.
  • Change priority and each non-closed status.
  • Add an internal note, staff reply and information request; reply as the reporter.
  • Test evidence permissions and teleport on an attached location.
  • Resolve one case, reject another and archive both; confirm closed cases reject normal actions.
  • Back up and separately verify the SQLite file.
  • Test one valid and one intentionally invalid webhook; case actions must succeed in both cases.
  • Change harmless wording, run /case reload and confirm the new text.

Manual Paper runtime testing remains necessary for inventory click routing and Dialog input on the exact server build used in production.
