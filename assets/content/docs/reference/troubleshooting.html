Plugin does not enable

  • Confirm Java 21 and Paper 1.21.11+.
  • Confirm the Paper Dialog API is present.
  • Inspect the log for runtime-guard or SQLite initialization errors.

/case does not open

  • Confirm the sender is a player with corecasex.use.
  • Confirm the plugin enabled.
  • Expect an inventory main menu, not a Dialog.

A player cannot create a case

  • Check corecasex.case.create.
  • Check the type's enabled key.
  • Check the open-case limit and in-memory cooldown.
  • Check required text fields and case-specific options.

Assignment fails

The target must be online and the case must be open. The inventory picker lists online players with staff-view permission; the direct command resolves an exact online name.

Claim or archive fails

Claim rejects already assigned or closed cases. Archive accepts only RESOLVED or REJECTED cases and rejects OPEN, CLAIMED, WAITING_PLAYER and WAITING_STAFF.

Evidence is missing

Check whether the flow collected that evidence and whether the viewer has corecasex.staff.view-evidence or corecasex.staff.view-sensitive-evidence. Last-death evidence exists only for deaths observed since the current plugin start.

Discord does not send

  • Confirm enabled: true.
  • Check priority, type, default and legacy route order.
  • Check the relevant event switch.
  • Inspect warnings for invalid URL, request failure or non-2xx response.

A config change does not apply

Run /case reload and read validation warnings. Restart after changing the JAR, Paper version or SQLite path. Remember that language and case-id-format are not active in 2026.1.1.
