CoreCaseX is a structured case-management plugin for a single Paper server. Players open guided support or moderation cases; staff triage the same records through an inventory-first board with ownership, evidence, conversation and final outcomes.

Version 2026.1.1 targets Java 21 and Paper 1.21.11 or newer. It stores its authoritative history in local SQLite and can mirror selected events to optional Discord webhooks.
