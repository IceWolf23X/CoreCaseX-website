Platform and Java

  • Java 21.
  • Paper 1.21.11 or newer with the Paper Dialog API and Player.showDialog.
  • Standalone Paper deployment. There is no Velocity, Bungee, Spigot or client module.
  • Modrinth also labels the project for Purpur; a Paper fork must expose the required Paper APIs.

Runtime guard

Startup checks the reported Minecraft version and required Dialog classes/method. If any check fails, CoreCaseX logs a clear error and disables itself before opening storage or registering the workflow.

Dependencies and integrations

Paper API is provided by the server. SQLite JDBC is shaded into the JAR, so no database service is required. Vault, PlaceholderAPI and a Discord bot are not required. Discord webhook output is optional and anonymous bStats reporting uses project ID 33073; server owners control metrics globally in plugins/bStats/config.yml.

Release maturity

The current source and newest Modrinth file are both 2026.1.1. Modrinth classifies that file as beta. This documentation therefore calls it the current build rather than presenting it as a stable production release.

Not in this version

There is no MySQL/MariaDB backend, proxy module, web dashboard, Discord bot command system, Discord ticket-channel creator or online-backup service.
