Purpose

storage.yml selects the SQLite file. SQLite is the only active backend in 2026.1.1.

Current bundled default

sqlite.path

The path is resolved relative to plugins/CoreCaseX/. The default data/corecasex.db becomes plugins/CoreCaseX/data/corecasex.db.

Blank paths, absolute paths and normalized paths beginning with .. are rejected, warn and fall back to the default. A changed path requires restart because /case reload does not reopen the initialized storage backend.

Backup

Stop the server before copying the database for the safest consistent backup. Back up the complete plugin data folder before changing the path or regenerating configuration. CoreCaseX has no online-backup command.
