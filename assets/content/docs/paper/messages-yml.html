Purpose

messages.yml supplies MiniMessage text for command feedback, notifications, bundled inventory items and Paper Dialog forms. Player-provided placeholder values are escaped before MiniMessage rendering.

Inventory menu keys

  • menus.titles.{main,case-types,my-cases,case-detail,staff-board,staff-case-list,staff-case-detail,staff-actions,assign,priority,status}.
  • menus.items.{create-case,my-cases,staff-board,open-by-id,back,close}.{material,name,lore}.
  • menus.lore, menus.navigation and menus.status are reserved empty groups.

Invalid or AIR material names fall back to PAPER. Code contains fallback lookups for additional internal inventory-item keys, but only the six item families above are part of the bundled public default.

Common placeholders

Common values include {id}/{case_id}, {staff}, {reporter}, {type}, {status}, {priority}, {assigned}, timestamps, location, description, counts and resolution fields. Use only placeholders shown by the bundled default for a specific key.
